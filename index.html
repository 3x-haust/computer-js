Computer.js

Your computer, now a browser API.

Websites can call real macOS functions — screen capture, mouse, keyboard, apps, files — after you approve them, once.

// A website can do this after you grant permission:
await computer.screen.capture();
await computer.mouse.click({ x: 500, y: 300 });
await computer.apps.open({ id_or_path: "Photoshop" });
await computer.files.reveal({ path: "~/Desktop" });
⬇ Download Runtime (DMG) ▶ Try: Send to Mac Control panel GitHub

Permission-first

Nothing runs until you approve it. Strong capabilities (screen, mouse, keyboard) always show a native macOS dialog.

Install once

One small native Runtime on your Mac. Then any website built with the SDK can use it.

Real OS calls

Not a sandbox. The Runtime drives actual macOS APIs — your cursor really moves, text really types.

Try it in 3 steps

  1. Install the Runtime — download the latest DMG, drag Computer.js Runtime.app into Applications, launch it. (It runs in the menu bar — it won’t pop a browser open.)
  2. Open the practical example — Send to Mac: paste text and push it to your clipboard, or capture your screen. It needs the Runtime running and your approval.
  3. Feels like magic — approve the native macOS dialog once, and the text lands on your clipboard / the screenshot is captured locally. Nothing is uploaded.
